# 카톡 '나에게 보내기' 누락 링크 확인·저장 가이드 (2026-11-07)

## 1. 왜 누락되는가 (원인)
| 원인 | 설명 |
|---|---|
| 카톡은 '보관함'이 아니라 '타임라인' | 메시지가 쌓일수록 과거 링크는 스크롤 아래로 묻힘. 검색은 본문 단어로만 가능 |
| 링크 미리보기 제목 ≠ 검색어 | 스크린샷처럼 미리보기 제목(예: "공공데이터 앱 아이디어 갤러리")은 카톡 검색에 안 잡히는 경우가 많음 |
| 읽기 API 없음 | 카카오는 '나와의 채팅'을 외부에서 읽는 API를 제공하지 않음. 자동 동기화가 불가능 → 사람이 내보내기(Export) 해야 함 |
| 저장 의도만 있고 '처리' 단계가 없음 | 보낸 뒤 분류·태깅·활용처 결정이 없으면 그대로 소실 |

## 2. 지금 당장 누락분을 확인하는 3가지 방법 (빠른 순)
### 방법 A. 채팅방 '링크' 서랍 (1분, 모바일)
'나와의 채팅' → 우측 상단 ≡ → **사진/동영상 · 파일 · 링크** 중 **링크** 탭
→ 그 방에서 보낸 모든 링크가 날짜순 목록으로 나옵니다. 빠진 게 있는지 가장 빨리 훑는 방법입니다.
(※ 톡서랍 플러스 가입자라면 '톡서랍 → 링크'에서 전 채팅방 링크를 한 번에 볼 수 있습니다.)

### 방법 B. 대화 내보내기 → 스크립트로 전수 추출 (5분, 권장)
1. **PC 카카오톡**: '나와의 채팅' 열기 → 우측 상단 ≡ → **대화 내용 → 대화 내보내기** → `.txt` 저장
   **모바일**: 채팅방 ≡ → 설정(⚙) → **대화 내용 내보내기** → '텍스트만 보내기' → 이메일/드라이브로 전송
2. 내보낸 파일을 이 폴더에 두고 실행:
   ```bash
   python kakao_links.py "KakaoTalk_나와의채팅.txt" --titles
   # 특정 날짜 이후만: --since 2026-09-01
   ```
3. 결과물
   - `*_links.csv` → Notion **🔗 카톡 링크 보관함** 에서 `··· → 가져오기(Import) → CSV` 로 업로드
   - `*_links.md` → 카톡/노션에 그대로 붙여넣기 가능한 카테고리별 목록

### 방법 C. 매주 5분 루틴 (재발 방지)
- 매주 일요일: 방법 A로 훑고, 새 링크는 Notion 보관함에 추가 → 상태를 '미확인'에서 '정리됨/보관/삭제예정'으로 이동
- 보낼 때 규칙: 링크 앞에 **한 단어 태그**를 붙여 보내기 (예: `#강의소재 https://…`). 카톡 검색이 `#강의소재`로 바로 됩니다.

## 3. 앞으로 '나에게 보내기' 대신 쓸 수 있는 경로 (비교)
| 경로 | 장점 | 단점 | 추천 |
|---|---|---|---|
| 카톡 나에게 보내기 (현행) | 가장 빠름, 습관화됨 | 보관·검색·분류 약함, API 없음 | 1차 캡처용으로만 |
| 카톡 + 매주 내보내기 + 스크립트 | 습관 유지, 전수 복구 가능 | 주 1회 수작업 필요 | ★ 현실적 최선 |
| 모바일 공유 시트 → Notion 앱 | 보관함에 바로 적재, 제목 자동 | 2~3초 더 걸림 | 중요한 링크는 이쪽 |
| Notion Web Clipper(PC) | 본문까지 저장 | PC 전용 | 기사·논문 |
| 북마크 앱(Raindrop 등) | 태그·검색 강력 | 도구 하나 추가 | 선택 |

## 4. 산출물

- `sample_pc.txt`, `sample_mobile.txt` : 형식 테스트용 샘플(스크린샷 기준으로 작성)

## 5. 한계와 확인 사항
- 카카오 공식 '읽기 API'가 없으므로 완전 자동화는 불가능합니다. (추정 아님, 2026-11 기준 Kakao Developers 문서상 메시지 '보내기' API만 존재)
- 스크린샷 2장에서 확인된 링크 5건(hollobit 2건, gonggong-api, 요즘IT 무료 AI 도구, Anytune)은 도메인만 보여 정확한 경로(URL)를 확인하지 못했습니다. 보관함에는 도메인 기준으로 등록하고 'URL 확인 필요' 메모를 남겼습니다.
- 내보내기 형식은 카톡 버전에 따라 달라질 수 있습니다. 파싱이 안 되면 파일 앞 10줄을 보내 주시면 바로 패턴을 추가하겠습니다.
